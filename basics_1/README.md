# 0x00. Networking basics #1

This project covers basic networking concepts, including the OSI model, TCP/UDP protocols, ports, IP addresses, and DNS resolution.

## Tasks

### 0. Change your home IP
Bash script that configures an Ubuntu server so that `localhost` resolves to `127.0.0.2` and `facebook.com` resolves to `8.8.8.8` by editing `/etc/hosts`.
